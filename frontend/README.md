# ScholarOS Frontend

React + Vite + Tailwind CSS로 구축된 ScholarOS 프론트엔드입니다.

## 기술 스택

- **React 18**: UI 라이브러리
- **Vite**: 빌드 도구 및 개발 서버
- **Tailwind CSS**: 유틸리티 우선 CSS 프레임워크
- **React Router**: 클라이언트 사이드 라우팅
- **Axios**: HTTP 클라이언트
- **date-fns**: 날짜 처리
- **lucide-react**: 아이콘

## 시작하기

### 의존성 설치
\`\`\`bash
npm install
\`\`\`

### 개발 서버 실행
\`\`\`bash
npm run dev
\`\`\`

서버 실행 후: **http://localhost:5173/**

## 주요 기능

⭐ **조교 배치 관리** (핵심 기능)
- 주간 캘린더 뷰
- 조교 배치 및 삭제
- 실시간 API 동기화

## 백엔드 연동

백엔드가 http://localhost:8000 에서 실행 중이어야 합니다.
